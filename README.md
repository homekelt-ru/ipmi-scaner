# IPMI Scanner

Сервис ищет в сети серверы с IPMI (BMC: iDRAC, iLO, IPMI Supermicro, XCC, iBMC и т.д.),
хранит их список и показывает его в веб-панели.

Без внешних зависимостей — нужен только Python 3.11+.

## Как работает

На каждый адрес по UDP/623 уходят два запроса, которые BMC обрабатывают **без логина**:

| Запрос | Что даёт |
|---|---|
| IPMI *Get Channel Authentication Capabilities* | факт наличия BMC, версии IPMI (1.5 / 2.0), разрешённые методы аутентификации, анонимный вход |
| ASF/RMCP *Presence Ping* | IANA-номер производителя (у части BMC) |

Найденные BMC при включённом `redfish` дополнительно опрашиваются через `https://<ip>/redfish/v1/`:
оттуда берутся производитель, модель и версия Redfish.

Рассылка идёт через один UDP-сокет с ограничением скорости, поэтому сеть /16 сканируется
примерно за минуту. Молчащие адреса переспрашиваются (`retries`). Старым BMC, которые
поддерживают только IPMI 1.5, запрос автоматически повторяется в формате 1.5.

Сервис также выдаёт предупреждения о небезопасных настройках: анонимный вход, пустые имена
пользователей, аутентификация NONE / пароль открытым текстом / MD2, только IPMI 1.5.

## Быстрый старт

```bash
# разовый скан
python3 -m ipmi_scanner scan 192.168.1.0/24 10.10.0.1-50
python3 -m ipmi_scanner scan 192.168.1.0/24 --redfish --json

# сервис с веб-панелью и плановыми сканами
cp config.example.toml config.toml   # укажите scan.networks
python3 -m ipmi_scanner -c config.toml serve
# панель: http://127.0.0.1:8623/  (снаружи — через ssh -L 8623:127.0.0.1:8623 host)

# сохранённый список
python3 -m ipmi_scanner -c config.toml list
```

## Вход в BMC и сбор данных

В панели у каждого BMC есть кнопка в колонке **BMC**: задайте логин и пароль, и сервис заберёт
модель, серийный номер, состояние питания, версии BMC/BIOS, процессоры, память, датчики
температуры и вентиляторов, потребление.

- Сначала используется **Redfish** (HTTPS), если он недоступен — **ipmitool** (IPMI 2.0 lanplus).
- Логин/пароль задаются для каждого BMC отдельно или один раз по умолчанию:
  `IPMI_BMC_USERNAME` / `IPMI_BMC_PASSWORD` (раздел `[bmc]` в config.toml).
  Кнопка **«Собрать данные»** заходит во все BMC в сети, у которых есть свои или стандартные данные.
- Сбор запускается только вручную, на каждый BMC делается **одна попытка входа**: при неверном
  пароле повторов нет, чтобы не заблокировать учётную запись на BMC.
- Пароли хранятся в базе SQLite **в открытом виде** (файл с правами 600, пароли никогда не
  отдаются через API). Используйте для сервиса отдельную учётную запись BMC с правами Operator
  или User, не Administrator.
- Если у панели нет пароля и она слушает не localhost, ввод паролей BMC отключён.

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/creds` | `{"ip", "username", "password"}`; пустой пароль — оставить прежний; `{"ip", "clear": true}` — удалить |
| POST | `/api/collect` | `{"ip": "..."}` или `{"all": true}` |

## Виртуальные CD/DVD (подключение ISO)

В окне BMC (кнопка в колонке **BMC**) есть блок **«Виртуальный CD/DVD»**: подключить образ,
отключить, посмотреть статус. Работает через стандартный Redfish VirtualMedia (HPE iLO 4/5/6,
Dell iDRAC 9, Lenovo XCC, новые Supermicro и др.). BMC сама скачивает образ по HTTP — это аналог
поля *Scripted Media URL* в iLO.

Образ можно взять:
- **из библиотеки** — на главной странице панель **«Библиотека образов (ISO)»**: нажмите
  «Загрузить образ», выберите файл (с индикатором прогресса), и сервис сразу покажет ссылку
  вида `http://<адрес сервиса>:8624/<файл>` с кнопкой «Копировать». Эту ссылку можно вставить
  в *Scripted Media URL* в iLO вручную, а в окне сервера она подставляется сама при выборе образа.
  Образы хранятся в томе Docker (`/data/images`), лимит размера — `IPMI_ISO_MAX_GB` (20 ГБ);
- **по URL** — любой http/https-адрес, доступный из сети BMC.

Галка **«Загрузиться с образа при следующей перезагрузке»** выставляет разовую загрузку с CD
(*Boot on Next Reset*). Сам сервер сервис **не перезагружает** — сделайте это в iLO или из ОС.

Требования и ограничения:
- порт библиотеки (`IPMI_ISO_PORT`, по умолчанию 8624) должен быть доступен **из сети BMC**;
  раздаются только файлы `.iso`/`.img`, только чтение, без листинга и без пароля;
- имя файла при загрузке: латиница, цифры, `.` `_` `-` (остальное заменяется на `_`);
  существующий файл не перезаписывается — сначала удалите его;
- загрузка и удаление образов без пароля панели разрешены только на localhost;
- нужны сохранённые логин/пароль BMC с правом управления виртуальными носителями
  (у iLO — *Virtual Media*, обычно роль Administrator);
- старые BMC без Redfish VirtualMedia не поддерживаются.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/iso[?ip=BMC]` | файлы библиотеки со ссылками |
| POST | `/api/iso/upload?name=x.iso` | тело — сам файл (`application/octet-stream`) |
| POST | `/api/iso/delete` | `{"name": "x.iso"}` |
| POST | `/api/media` | `{"ip", "action": "status"\|"insert"\|"eject", "file"\|"url", "boot_once"}` |

## Docker

```bash
cp .env.example .env        # укажите IPMI_NETWORKS и пароль панели
docker compose up -d --build
docker compose logs -f

# разовый скан из контейнера
docker compose run --rm ipmi-scanner scan 192.168.1.0/24 --redfish
```

Контейнер запускается в режиме `network_mode: host`: так сканер видит все сети хоста и
получает MAC-адреса BMC из ARP-таблицы. База хранится в volume `ipmi-data` (`/data/ipmi.db`).

Все настройки задаются через переменные окружения из `.env.example`, они перекрывают
`config.toml`. Чтобы открыть панель наружу, задайте `IPMI_WEB_LISTEN=0.0.0.0` и обязательно
`IPMI_WEB_PASSWORD`.

Пошаговая установка на сервер: [INSTALL-ALMALINUX.md](INSTALL-ALMALINUX.md).

## Установка как systemd-сервиса

```bash
sudo ./deploy/install.sh
sudo nano /etc/ipmi-scanner/config.toml   # сети, пароль панели
sudo systemctl restart ipmi-scanner
journalctl -u ipmi-scanner -f
```

## API

Если задан `web.password`, все запросы требуют Basic Auth. POST-запросы принимают только `application/json`.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/hosts` | все найденные BMC |
| GET | `/api/scans` | последние сканы |
| GET | `/api/status` | идёт ли скан, время следующего планового |
| POST | `/api/scan` | `{"targets": ["10.0.0.0/24"]}` или `{}` — сети из конфига |
| POST | `/api/note` | `{"ip": "...", "note": "..."}` |
| POST | `/api/delete` | `{"ip": "..."}` |

## Ограничения

- Только IPv4.
- MAC-адрес виден только для BMC в одном L2-сегменте со сканером (берётся из ARP-таблицы).
- Сканировать можно только сети, на которые у вас есть права.
